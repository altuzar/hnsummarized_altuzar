This causes high-resolution details from earlier layers to be averaged out as they propagate through many layers, forcing networks to recompute information and reducing learning efficiency.

DCA reframes residual learning as a dynamic routing problem through two mechanisms. First, it introduces dynamic layer routing where each token gets unique mixing weights combining a static learnable base with input-dependent projection, allowing the network to shift its processing structure contextually. Second, depth-wise cross-attention applies attention across layers in depth rather than across tokens in sequence, letting each token query a weighted mix of all prior layer embeddings.
