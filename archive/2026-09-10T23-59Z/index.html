    364 points by soheilpro · 15 hours ago · 179 comments

Rather than counting files then picking a random index (two passes), it used one-pass reservoir sampling: iterate through files, with each file having probability 1/n of being selected, avoiding repeated filesystem calls and handling directory changes mid-enumeration. It capped selection at 100 files to prevent pathological cases.
