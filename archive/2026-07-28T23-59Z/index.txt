Standard A* relies on distance-based heuristics (Manhattan, Euclidean) that don't account for map structure and often point searchers in wrong directions. The technique precomputes shortest paths from every node to a small set of "landmark" nodes (e.g., 4–8 points), then uses the triangle inequality to derive tighter lower bounds: cost(B,X) ≥ cost(B,L) - cost(X,L). At query time, the heuristic function takes the maximum across all landmarks, improving guidance without modifying A* itself.

Key insight: a single landmark only helps if it's "past" the goal—that is, if the start-goal path passes through or near a line from goal to landmark. Multiple strategically-placed landmarks cover different directions and path types. Placement is application-specific: high-traffic areas like dining halls in Dwarf Fortress deserve landmarks, while random-path analysis can find placements automatically if map structure isn't known in advance.

The author spent 11 years understanding this technique sufficiently to explain it clearly. Starting from quadratic softmax attention, the author removes softmax normalization to get linear attention with fixed-size state S_t = Σ |v_i⟩⟨k_i|, which stores summed outer products of past keys and values. This achieves O(n) instead of O(n²) complexity but introduces a fundamental problem: addition instead of assignment. When a new (k,v) pair is written and immediately read, the result adds to whatever the state already predicted rather than replacing it, corrupting past associations.

DeltaNet solves this via delta-rule correction: compute the error between desired output |v_t⟩ and current prediction S_{t-1}|k_t⟩, then write only that error scaled by learned parameter β_t ∈ [0,1]. This is derived two ways: (1) demanding the write be readable back immediately, and (2) as one gradient descent step on reconstruction loss. The update becomes S_t = S_{t-1} + β_t(|v_t⟩ - S_{t-1}|k_t⟩)⟨k_t|, which replaces old associations along the current key direction while preserving orthogonal directions.

However, this targeted correction doesn't address stale information in other directions. Gated DeltaNet adds a scalar retention gate α_t ∈ [0,1] applied globally: S̃_t = α_t S_{t-1} before the delta update. This provides whole-state forgetting.

Kimi Delta Attention's key innovation is replacing the scalar α_t with a per-channel vector α_t ∈ [0,1]^{d_k}, applied as diagonal multiplication S̃_t = S_{t-1} Diag(α_t). Now each key channel decays independently, allowing selective forgetting of stale information in specific directions while preserving recent relevant context. The state transition becomes diagonal-plus-low-rank (DPLR), which enables efficient chunked computation.
