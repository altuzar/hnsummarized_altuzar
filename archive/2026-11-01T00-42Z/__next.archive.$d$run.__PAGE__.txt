Stage 1 appends an attacker's Ed25519 public key (comment "svc-telemetry") to ~/.ssh/authorized_keys and attempts to enable SSH via systemsetup on macOS, systemctl on Linux, or PowerShell on Windows. A critical bug affects macOS: the malware runs systemsetup -getremotelogin without elevation; when run as a standard user, this fails with an "administrator access" error printed to stdout and exit code 0. The malware's logic treats this error output as "SSH is on" rather than "permission denied," skipping the enablement step entirely. This breaks the backdoor on Macs without pre-existing SSH access.

Stage 2 establishes an outbound SSH tunnel to 134.209.82.225:22, authenticated with an embedded unencrypted Ed25519 private key (comment "svc-telemetry-tun"). The tunnel uses remote port forwarding (-R *:0:localhost:22) to dynamically allocate a listening port on the attacker's server, forwarding traffic back through the tunnel to the victim's SSH daemon. The tunnel runs detached with autossh or ssh, retrying every 60 seconds.

Stage 3 creates platform-specific persistence: on macOS, a LaunchAgent (~/Library/LaunchAgents/com.apple.sysmond.plist) with RunAtLoad and KeepAlive set true, disguised with an Apple-like name; on Linux, an @reboot crontab entry; on Windows, a scheduled task or Startup folder script. All platforms drop the tunnel key and reconnection script to ~/.config/.

Stage 4 gathers host reconnaissance (hostname, username, OS, architecture, Git email, public IP, environment variable names matching KEY|TOKEN|SECRET|PASS|AWS|GCP patterns) and sends a one-off HTTP beacon to the attacker's server at 134.209.82.225:8099. Only variable names—not values—are exfiltrated, giving the operator inventory of which credentials exist on the machine.

The injection point is an IIFE prepended to extension.js that executes before the extension's normal activate callback, requiring no user interaction. The malware uses Node.js file APIs directly, bypassing shell-based detection, and disables host-key checking and known_hosts verification for the SSH connection.
