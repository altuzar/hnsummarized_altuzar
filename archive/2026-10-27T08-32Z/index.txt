Context confusion: unrelated facts influence model behavior in hard-to-predict ways. Context clash: tools and memory systems conflict.

Six established fixes are now deployed in code harnesses rather than prompts: context augmentation (RAG/skills), tool loadout (filtering which tools to expose), context quarantine (subagents with blank history), context pruning (removing unneeded turns), context offloading (storing info externally), and context summarization/compaction.

Two new failure modes emerge from agentic models: fighting the weights (models overfitting to training environments, requiring repetitive system-prompt corrections toward parallelism or different tool patterns) and context inertia (models fixate on one subtask and won't stop pursuing it). Solutions: clearing context hourly while preserving environment artifacts (Anthropic's Memento approach), periodic forgetting during long research tasks (Microsoft's Fork-and-Flush), and full-context resets.

Core prescription: move from "make context bigger" to "teach models to manage context." Around 200k–300k tokens is Breunig's warning threshold; beyond that, he resets. The final challenge he predicts: as personal agents run for months, accumulated memories and skills conflict and contradict, requiring strategic forgetting nobody has solved yet.
