12:Tcc3,Tailscale's managed networking service experienced repeated database corruption from August through early 2025, with 19 separate incidents over six months despite using SQLite in its documented single-writer, single-process architecture. Each incident caused 30-minute to hour-long outages affecting control plane operations: new devices couldn't get peer lists, the admin console went dark, and API calls failed. The control plane uses per-shard SQLite databases with a single Go process per database.

The root cause: a 16-year-old data race in SQLite's WAL (Write-Ahead Logging) checkpoint process. When a write transaction collided with WAL-reset operations at precise timing, the checkpoint believed it had copied pages from the WAL to the main database, but hadn't. Those pages were permanently lost, and referencing pages (like indexes) written afterward corrupted the file. SQLite developers had to add instrumentation to deliberately trigger the bug in tests because it was so rare.

Tailscale's investigation strategy: Since standard reproduction failed, they deployed a transaction logging pipeline that replayed all SQL writes. This revealed data writes vanishing between commits—impossible behavior that hinted at a low-level race. They engaged SQLite on a support contract and worked with their developers to build a tmstmpvfs VFS shim (now in the public SQLite repo) providing enhanced filesystem-level logging. The shim caught the race in action during the next incident.

Fix deployment: SQLite 3.51.3 added checkpoint validation. A parallel 3.52.0 release also optimized text-to-float conversions, which exposed a stale expression index bug in Tailscale's timestamp columns (converting high-precision text to floats in virtual columns). After recovery, SQLite released 3.53.0 with self-healing indexes. Tailscale reduced timestamp precision to integer seconds on their side.

Proof of fix: They patched their driver to log warnings when write/checkpoint overlaps occurred. Two months after deployment, one warning fired—proving the precise race condition existed in production and the fix prevented corruption. Four months of clean operation followed.
