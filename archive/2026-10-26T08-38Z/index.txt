Values are constructed in-place at their final destination and freed when their scope exits. The core innovation is that as resizable arrays grow by bumping a pointer, nothing moves, so references into growing arrays remain valid indefinitely. This eliminates the reallocation problem that plagues C++ vectors and Rust Vecs.

The language compiles to C and runs on Windows, macOS, and Linux. It features familiar C/Rust-like syntax but with unique capabilities: nested data stays inline (a record with variable-size fields is one contiguous block), enums cost only their variant's size not the largest variant, relative references store typed offsets as 1-4 bytes instead of 8-byte pointers, and data structures can be serialized as-is with zero-copy deserialization and cryptographic validation of links. Functions return errors across multiple stack frames without Result types or unwinding. Threads share nothing; workers are compiled as separate programs and exchange only flat values through typed queues.

Benchmarks are substantial: geometric mean over 16 tests shows 3.51x speed vs idiomatic C++ (1.24x vs hand-optimized, 1.13x vs best safe Rust) using 1.95x less memory. Speed comes from no allocation overhead, contiguous data layouts, narrow links, and sized enums. The author is Wouter van Oortmerssen (Aardappel on HN), who created Lobster, and he's active in the comments doing an AMA.
