Main bug categories: (1) TOCTOU races—the largest cluster. APIs like fs::remove_file then File::create re-resolve the path twice, and an attacker controlling the parent directory can swap in a symlink between calls. Fix: use create_new(true) or anchor on file descriptors via openat-style APIs. (2) Lossy UTF-8 conversion. comm used from_utf8_lossy, silently corrupting binary files. Fix: stay in bytes with Vec<u8> or OsStr. (3) Permission races. Creating a directory then fixing permissions leaves a window where others can open it. Fix: set permissions at creation with mode() or DirBuilderExt::mode(). (4) String path comparisons. chmod checked if path=="/" but was bypassed by "/../" or symlinks.
