However, the authors show via novel "role probes" that LLMs don't reliably use these tags to determine roles; instead they infer roles from writing style.

The methodology is elegant: they wrap identical neutral text in different role tags and train linear probes on model activations to measure CoTness (perceived reasoning), Userness (perceived user text), etc. Crucially, when they remove tags entirely, CoTness for reasoning-like text remains unchanged—suggesting the model learned "reasoning-style writing = my thinking" rather than "think tags = my thinking." When they re-wrap everything in user tags, reasoning-style text still scores high CoTness, proving writing style overrides structural tags.

This leads to two concrete attacks. First, "CoT Forgery": injecting fake reasoning blocks spoofed to match the model's reasoning style (terse syntax, particular phrases). Tested against late-2025 frontier models, this lifts attack success from near-zero to ~60% on jailbreak benchmarks. The attack transfers across models because it exploits something structural. Second, simple prompt injection where attackers prepend "User:" to commands in tool output—the model's Userness probe shows it then misperceives tool data as user instructions.

Both attacks are quantitatively predictable: attack success correlates strongly with how much the role probes measure confusion.
