24:T782,Java4Shell is a critical heap memory-corruption bug in OpenJDK 17.0.6+ running on x86-64 processors with AVX-512 VBMI. The vulnerability lives in hand-rolled assembly code for fast Base64 decoding. When given input like 64 'A' characters followed by '=', the decoder miscalculates a padding mask, turning a correct 50-byte write into a 64-byte write, corrupting heap neighbors. The researchers demonstrated pre-auth RCE in Keycloak, Jira, Confluence, Artifactory, Jenkins, and PingFederate; post-auth RCE in Kafka, Solr, Elasticsearch. Exploitation requires sophisticated heap grooming ("Feng Shui"), controlling memory allocation order across network requests using TCP timing, and app-specific payloads. The attack is fragile: sensitive to network RTT, requires bespoke profiles per target, vulnerable to request buffering proxies.

The researchers (Calif) used AI ("centaur hacker" methodology) to discover and develop exploits, spending under $200 in token costs and roughly three hours end-to-end. 2c:Tcfc,Josh McKinney has developed a terminal protocol feature called cell borders that allows drawing lines on the edges of terminal cells without consuming space like traditional box-drawing Unicode characters. The feature is implemented as a Device Control String (DCS) extension in patches to Ghostty and Rio, allowing borders to be specified as cell attributes similar to background colors.

Technical approach: Each cell carries up to twelve line segments (two halves on each of four edges plus four arms from center), each with configurable color, width, placement, and style. 3f:T82d,e-means is a modern replacement for Lloyd's k-means algorithm developed at Meta FAIR. The core insight replaces Lloyd's full-batch updates with mini-batch exponential moving average (EMA) updates: S_j ← (1-α)S_j + αs_j instead of S_j ← s_j. This allows the centroid to track recent assignments rather than the full history, making the optimization landscape noisier and better at escaping local minima. Combined with cosine-scheduled learning rate decay, improved initialization, dead-cluster revival via proportional splitting (not random resampling), and finalization stage, e-means needs only 1.2-3 epochs to reach Lloyd's loss at 25 epochs.

The paper validates extensively across 24 datasets with 100k-100M points. Wall-clock speedups: 10-45x vs Flash-KMeans on GPU (H100), 8-15x vs Faiss on CPU. Toy visualizations show e-means escapes pathological configurations (Lloyd stuck 15-46% of starts, e-means 0-3.5%). A key contribution is automatic hyperparameter selection: scaling laws fit to problem dimensions (n, k, T) automatically set batch size B and initial step α₀ without tuning, generalizing well to held-out datasets (R² ≈ 0.95). Dead-cluster revival is critical for large codebooks—proportional splitting reduced dead clusters from 2,343 (EnCodec resampling) to 47 on DEEP dataset (1M vectors, k=16,384).
