7:T961,Fugleramme is a complete DIY bird-identification display frame for Raspberry Pi that combines audio detection with historical natural-history artwork. It renders these on a 13.3-inch Inky Impression e-ink panel, arranged by body mass with larger birds toward center, and redraws only when new detections arrive. The creator has curated over 800 cutouts from 400+ species (mostly Scandinavian, British, and central European sources), and the system runs fully local without cloud dependencies. A web kiosk interface mirrors the e-ink display for HDMI screens, plus an admin panel for configuration. Installation uses Docker or a bash script on Pi; development uses Python with hot-reload locally.

The project's GitHub link itself failed to load, but the README content shows solid documentation including hardware specs, Docker support, and contribution guidelines. The creator explicitly states "no art is AI-generated, though some has been retouched with AI"—a claim that sparked the most heated comment thread.

f:T9e4,Dmitry Brant created an interactive 3D environment where the speed of light is 5 km/h—a brisk walk—to make relativistic effects intuitive at human scales. You navigate with arrow keys and mouse, watching stationary objects like lampposts that flash once per second, a spinning Ferris wheel and carousel at 75% light-speed, and a shuttlecraft. As you accelerate toward light speed, length contraction compresses objects, time dilation causes world clocks to tick differently than your watch, optical aberration narrows your field of view ahead and widens it behind, Doppler shifts color objects blue ahead and red behind, and relativistic beaming piles light forward. You can toggle effects on and off to isolate phenomena.

The comment section confirms the physics is notably more accurate than MIT Game Lab's 2012 "A Slower Speed of Light," which had temporal Doppler effect bugs. One commenter verified the temporal component is correct here. Several others mention related works: George Gamow's 1951 book "Mr. Tompkins in Wonderland" which explored similar thought experiments, the 1990 novel "Redshift Rendezvous," and the free game "Velocity Raptor" by Test Tube Games (speed of light set to 3 m/s, with puzzle levels explaining the physics). A few Discworld references appear, and one commenter notes the Three Body Problem trilogy explores changing light-speed locally.

A sophisticated objection emerged: one physicist flagged that Lorentz-invariant non-parallel sequential boosts should decompose into a boost plus spatial rotation, but the simulation doesn't seem to show this Thomas precession effect visibly. Another commenter notes that mathematically, you can't truly "change the speed of light" independently—it's entangled with the fine-structure constant, mass-energy equivalence, and information propagation. What's actually being varied is the observer's perception. Someone humorously noted that atomic bombs wouldn't work (E=mc² with small c yields negligible energy). One physicist asked about light-travel time showing car roofs on the Ferris wheel when the geometry shouldn't permit it.

User experience issues dominate the remaining comments: no mobile controls (arrow buttons requested), confusing directional feedback, one report of cursor capture persisting after leaving the page in Firefox, and requests for a direction indicator and mobile incompatibility warning. One user had issues with back-arrow reversals near zero velocity.
