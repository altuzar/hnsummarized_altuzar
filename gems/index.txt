23:T8b8,Transformer Explainer is an interactive single-page tool that walks through transformer architecture using a live GPT-2 (small) model running in the browser via ONNX Runtime. The visualization covers the full pipeline: tokenization splits input into 50,257-token vocabulary IDs; token embedding converts tokens to 768-dimensional vectors; positional encoding adds sequence position information; 12 stacked transformer blocks process data through multi-head self-attention (which computes Query/Key/Value matrices and applies masked attention) and MLPs that expand to 3072 dimensions then compress back; finally a linear layer outputs logits over all tokens, which softmax converts to probabilities for sampling. Temperature, top-k, and top-p parameters control generation randomness. The interface is built with Svelte and D3.js, created by Georgia Tech researchers.

Comments identify both strengths and limitations. Praising reviewers call it one of the better visualizations available, with particularly insightful interactive attention maps. One commenter notes the elegant insight that attention heads effectively learn to construct small single-layer networks dynamically via Query/Key products forming weights. However, multiple critics raise valid concerns: the explanation conflates temperature with "safety" when lower temperatures actually produce monotonous artificial-sounding text; the visualization uses GPT-2's absolute positional encoding which modern models have abandoned for RoPE or ALiBi, potentially misleading learners about current architectures; Query/Key/Value weight matrices—the core learnable parameters—are not presented prominently enough upfront and should be shown per-head; and the page consumes 2.2GB RAM rapidly, causing performance issues on resource-constrained devices.
