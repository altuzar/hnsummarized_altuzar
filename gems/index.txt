1b:Tf3a,Simon Edwardsson fine-tuned Qwen2.5-Coder-0.5B (360M parameters) to act as a terminal simulator. Rather than predicting token sequences, the model predicts changes to a 2D grid of characters—which rows to rewrite and cursor position—from raw keypress bytes. Tokenization reuses 256 byte values plus 64 row indices for a minimal 333-token vocabulary. A clever COPY operation lets the model reuse previous rows (scrolling costs 3 tokens per row instead of 3000). Training used 336k synthetic terminal sessions from Docker containers running real commands, with data generation tracking consistent state across file edits, vim sessions, tmux panes, and typos. The model was trained with supervised fine-tuning, then improved via a DAgger-inspired self-correction loop: when the model makes errors during inference, the training process generates repair examples teaching it to fix itself on the next keypress, provided any words in the correction appeared earlier on real screens. This single change improved memory readbacks from 24/47 to 38/47 on PresetBench (int4 quantization). Performance was critical: early autoregressive decoding generated 3000 tokens per full redraw (up to 12s). Solution was parallel row generation—each row gets one batch element, reducing it to ~100 steps. But independent rows can't coordinate (vim opens on wrong row). Fixed via speculative decoding: rows draft in parallel, then verified sequentially, keeping only tokens up to first disagreement. On M4 Mac: single character ~60ms, man pages ~2.5s with parallel drafting. The model was shrunk from 494M to 360M by dropping unused vocabulary tokens, then quantized to int4 (208MB) for WebGPU inference in the browser.

Results: it handles simple commands and can maintain files across sessions (9/13 memory readbacks correct vs. 2–3 for prompted models), supports vim/tmux mode switching and tmux panes, runs snake autonomously, and even attempts Python REPL. Failures: nested directories cause position confusion, Python produces GPT-3-era hallucinations on complex operations, echo output doesn't always persist correctly (cat doesn't show appended lines). Distillation experiments showed layer 7 critical for memory—removing it tanked readbacks to 0/64 despite preserving next-token accuracy to 98.9%. Author tested three benchmarks: ShellBench (106 commands, 52→80 correct), PresetBench (47 scripted cases), and memory worlds (32 filesystems with two-value readbacks). 3a:Tdea,Cammarata presents a major reframing of neural network interpretability, arguing that decades of evidence for "polysemanticity" (neurons responding to unrelated concepts) rested on methodological errors. The two canonical examples he helped establish are re-examined: the InceptionV1 neuron 4e:55 (cats and cars) is actually a V-shape detector, and the original superposition circuit showing cars hiding among dog neurons actually reflects shared pose features across categories. He attributes past confusion to weak feature visualization tools (which reward-hack toward dog neurons in deeper layers), architectural limitations in InceptionV1, and lack of understanding about generalized pose neurons.

His core argument: networks use one learning principle (generalization), not two (generalization plus superposition). Recursive generalization—where neurons sprout related sub-concepts as they grow—explains apparent polysemanticity. In retrained InceptionV1, moving from ~0% interpretable neurons in the last layer to 99-100% required only ordinary architectural improvements, no model scaling. In large language models like Qwen3-32B, preliminary audits find ~90% of neuron poles have one main job, ~7% have two related jobs, and only ~2-4% remain unexplained.

He emphasizes that interpretability compounds—like a jigsaw puzzle, each explained neuron constrains surrounding ones. Once you understand motifs (e.g., subtle-feeling detectors firing on punctuation), subsequent neurons become easier to identify. Modern tools enable agentic iteration: conjecture, test, refine. He trained vision models across 300× size ranges and found consistent legibility at all scales; with constrained models, neurons just represent coarser concepts (one neuron for many car types vs. separate neurons per car). In larger models, neurons differentiate into narrower, easier-to-recognize features.
