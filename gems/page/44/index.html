  1. ★
    Show HN: TinyPDF – 3kb pdf library (70x smaller than jsPDF)(github.com)

    ★ Functional, lightweight PDF generator with multiple runnable examples and clean API…

    TinyPDF is a 3.3KB PDF library (70× smaller than jsPDF) with zero dependencies that generates invoices, receipts, and reports using only TypeScript. It supports text, rectangles, lines, JPEG images, and multiple pages but omits custom fonts, PNG/SVG, forms, encryption, and HTML-to-PDF. Commenters noted it only handles ASCII/Latin script and lacks bold/italics, but praised the minimal codebase and usefulness for standard document generation tasks.
