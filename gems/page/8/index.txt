1f:Ta97,Zakaria's previous article proposing executable-as-SQLite resonated widely. SELF extends this by storing not just program code but all application state—routes, content, logs, configuration—in a single queryable database file. The interpreter uses binfmt_misc to intercept execution, mapping ELF segments to database rows, then jumps to the entry point. Crucially, the running program retains write access to its own file via argv[0], allowing live updates and persistent state without separate /var, /tmp, or /home directories.

The self-httpd proof-of-concept serves a website where every visitor interaction (GET requests, button presses) is recorded as rows. The schema includes three simple tables: routes (path, mime, body), visits (id, timestamp, user-agent, path), and presses (id, timestamp, button). Updates are atomic—sqlite3 can query or modify the running server's data mid-flight. Asset pipelines become trivial SQL INSERTs. Full-text search via FTS5 and audit diffs via sqldiff work transparently since the file is already a database.

Deployment simplifies to scp'ing one file. Upgrades are data migrations: ATTACH old version, INSERT...SELECT data into new version, swap and restart. Zero-downtime updates could use SIGHUP-triggered fork/exec with file-descriptor handover, theoretically with clever BLOB alignment for mmap'd segments.

37:Tbf7,Edwardsson trained a 125M transformer to continue piano pieces from brief MIDI prompts, deployed as a free iOS app called RollTab. After 14 experiments over nearly a year, he achieved real-time on-device inference (108 notes/sec on iPhone 15).

The core technical breakthrough was tokenization: instead of separate NOTE_ON/NOTE_OFF tokens causing drift in small models, he uses NOTE(pitch, delta_onset, duration, velocity) with a nested decoder for the five categorical fields, advancing by one complete note per transformer pass rather than one field per step. This 5x acceleration matters for live play. Sustain pedal is baked into note duration during preprocessing to simplify the problem. Timing quantizes to 24 steps per quarter note (handles triplets and human imprecision).

Dataset: ~300M note events from hundreds of thousands of MIDI files (mostly public-domain classical), heavily cleaned and deduplicated. Counter-intuitively, scaling to 5x size made models worse—data quality mattered more than quantity. Training used cross-entropy on separate heads (pitch, delta, duration, velocity) for transparency. Scheduled sampling (randomly feeding predicted fields back instead of ground truth during training, up to 50%) increased validation loss but improved continuations. For evaluation, Gemini 3.5 Flash pairwise comparison outperformed absolute scoring.

DPO (Direct Preference Optimization) made the biggest impact: base model had 24.55% preference rate vs. 69.05% post-DPO consensus training (β=0.03). Model was exported to Core ML with INT8 quantization; context window is 512 notes, rebuilt as needed.
