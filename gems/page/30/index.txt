1f:Ta07,The article explains how signals—reactive values adopted by Solid, Vue, Preact, Angular, and Svelte—propagate changes through computation graphs via a push-pull algorithm. A signal wraps mutable state with subscribers; when updated, it notifies dependents immediately (push/eager). A computed derives values from signals/computeds, caching results and updating only when accessed if dependencies changed (pull/lazy). The magic linking mechanism uses a global STACK array. When a computed executes, it pushes metadata onto STACK. Any signal accessed during that execution reads STACK, discovers the running computed, and registers itself as a subscriber. This auto-tracks dependencies without explicit lists like React's dependency arrays. A dirty flag marks computeds as invalidated; re-evaluation only happens when their value is read. Sources (dependencies) are cleaned up on each recompute so dead subscriptions don't accumulate and the dependency graph stays accurate.

The article includes working TypeScript code for both signal and computed implementations, demonstrating the complete flow: signal update triggers push notifications down the graph, marking computeds as dirty; reading a computed's value triggers pull-based re-evaluation up the dependency tree, recalculating only what's needed. 37:Td4d,Rune Skovbo Johansen describes an 8-month effort to develop a fast erosion filter that mimics the appearance of water-carved terrain without simulating water. The technique builds on prior Shadertoy work by Clay John (2018) and Fewes/Felix Westin (2023), combining multiple innovations.

The core approach uses rotated stripe patterns (sine/cosine waves) aligned to terrain gradients. Water flows downslope, so negative gradient vectors indicate flow direction. By layering these stripe patterns at multiple octaves (scales) and blending adjacent cells, the technique creates gullies and ridges that naturally follow slopes. The key innovation solving the "chaotic mess" problem is dividing the pattern into cells with independent pivot points, similar to Worley noise, preventing excessive distortion far from rotation centers.

The original technique had two problems: peaks looked wrong (arbitrary height offsets), and valleys developed unwanted bulges. Johansen presents two solutions. The "frequency approach" (Clay John/Fewes) makes stripe thickness inversely proportional to slope steepness—at peaks/valleys where slope approaches zero, stripes become infinitely thick, always landing on ridge portions of the pattern. However, this creates valley bulges at full strength. Johansen's "fade approach" keeps stripe widths consistent but fades stripe influence toward white (ridge) at peaks and black (valley) at valleys, achieving crisp features everywhere when properly parameterized.

Three additional refinements address crispness. "Stacked fading" updates fade targets and masks through each octave, preventing smaller gullies from appearing directly on larger ridges. "Normalized gullies" treats interpolated sine/cosine pairs as unit circle points, normalizing magnitude to ensure consistent gully sizes (with clamping at 0.5 threshold to avoid loopy artifacts). "Straight gullies" uses the sign of sine waves rather than their values to fake constant slopes through gully cross-sections, forcing smaller gullies to branch cleanly from larger ones instead of curling parallel.

Implementation outputs both heights and analytical derivatives. The author also released "Phacelle Noise," a directional noise function extracted from this work. Shadertoy provides both a beginner-friendly implementation and an advanced one.
