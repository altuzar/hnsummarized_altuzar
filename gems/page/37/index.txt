The core innovation encodes each pixel as a 3-byte tuple: the normal map's azimuth angle in spherical coordinates (Nφ), a log-space coefficient m, and a bias term b. Real-time computation reduces to: multiply the coefficient by cosine of angle difference (using lookup tables), add bias, and output via another lookup. The math reformulation v = m·cos(Nφ - Lφ) + b with fixed Lθ allows precomputing m and b at compile time, leaving only two 8-bit lookups and three additions per pixel.

The 8-bit arithmetic is extreme but functional: scalars range -1.0 to +1.0 in linear space using 127 as the denominator (to represent ±1 in two's complement). Log-space uses 2^(1/6) as base, scaled to 8 bits, with MSB as sign bit. Addition uses linear-space values (simple byte addition), multiplication uses log-space (byte addition followed by pow lookup). The implementation processes 15 screen tiles per frame in ~124K cycles of the 139K-cycle budget (~89%), with intentional visual tearing from partial rendering per frame. Assembly-level optimization includes self-modifying code to hardcode loop constants, saving 10% of shader runtime by avoiding memory loads.
