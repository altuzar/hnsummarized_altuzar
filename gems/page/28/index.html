    ★ Interactive game tree visualizer with beautiful 3D graph rendering, steady-state diagram…

    WeakC4 is a search-free weak solution to 7x6 Connect 4 that fits in 12KB and requires no runtime computation. It identifies patterns ("simple tricks" like ClaimEven) that reduce game play to memorizing a 2,600-node opening tree whose leaves all have straightforward endgame strategies.
