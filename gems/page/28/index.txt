This matters because it keeps arithmetic closed while maintaining the inclusion property: any real numbers picked from input intervals, when computed normally, yield results guaranteed to fall in the output set. The author cites a 2017 "Interval Unions" paper by Schichl et al.

Key implementation details: dependency-free TypeScript library using IEEE 754 double-precision with outward rounding. This means computed intervals mathematically contain the true value despite floating-point errors. Full precision mode demonstrates 0.1+0.2 = [0.29999999999999993, 0.3000000000000001], capturing the rounding error. Supported operations include standard arithmetic, exponentiation, trigonometric functions (including tricky ones like tan that produce disjoint outputs), logarithms, and utility functions like hull() and sqinv() (inverse of squaring, properly returning both roots). 27:Tc38,I-DLM solves a fundamental problem with diffusion language models: they traditionally lag behind autoregressive models in quality because they fail at "introspective consistency"—DLMs learn to denoise but not to verify their own outputs. The key innovation is introspective strided decoding (ISD), which generates N tokens per forward pass while simultaneously verifying previously generated tokens using a p/q acceptance criterion based on the base AR model's logit distribution. This unifies generation and verification in one pass, mimicking how AR models train.

The method converts any pretrained AR model (they use Qwen3) via three components: (1) causal attention masking, (2) logit shift for position 1, and (3) an all-masked objective.
