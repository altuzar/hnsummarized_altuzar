    You could have invented transformers from memory(alexwang.ai)

    ★ Interactive slider-based visualizations showing interference-to-signal tradeoffs across…

    Wang derives transformer components from memory-store principles. Starting with outer-product memory, he incrementally builds toward self-attention by analyzing interference patterns and capacity. MLPs emerge as nonlinear memory stores; softmax-based attention achieves exponential capacity (~1.2M memories at d_k=64) by raising similarities to infinite powers via exponentials. Comments praise accessibility but note some want concrete examples; engineers appreciate the signal-processing framing.
