19:T8de,This is a standalone Vulkan reimplementation of NVIDIA's DLSS 5 Neural Rendering (NR) network—not an upscaler, but a neural post-process that re-renders frames with injected noise and learned adjustments. The network is 71 transformer blocks arranged in a U-net with a global ViT at the bottom, running FP8 activations on tensor cores. Performance: 2.8ms at 768x768, 7.8ms at 1920x1080, 29.3ms at 4K on an RTX 4070 Super. The implementation is bit-exact against the original at every intermediate boundary (all 75 block boundaries), byte-for-byte. A second WebGPU port provides the same exactness in a browser without tensor cores or FP8 fusion, running 72ms at 512x512. The author includes detailed documentation of the network graph, execution scheduling, temporal feedback paths, and numeric verification. Build requires Windows, Ada+ GPU, VS2022, and model weights (which the repository does not provide). Extensive tuning switches allow falling back to GLSL reference kernels or disabling fusion.

The comment section adds valuable context: many are impressed by the bit-exactness ("sorcery"), but several raise practical concerns. A key tension emerges around generalization: NVIDIA historically ships per-game models trained on game-specific data, so without knowing whether this is a single generalized model or per-game, the practical utility is unclear.
