    Linux for the Sega MegaDrive(github.com)

    ★ Interactive Linux shell running on original MegaDrive hardware with video output…

    Someone successfully ported Linux 7.1 to the Sega MegaDrive using a Mega EverDrive cartridge that provides 4MB RAM (the console has only 64KB native).
