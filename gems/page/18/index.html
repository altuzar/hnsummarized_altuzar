    Fable created novel 4D splat format(adamraudonis.github.io)

    ★ Interactive browser demo with live streaming, real-time decoding, orbit/zoom controls…

    Fable released splat4d, a compressed 4D gaussian splat format achieving 16-58× compression over raw frames and 14-20× over gzip.     Someone successfully ported Linux 7.1 to the Sega MegaDrive using a Mega EverDrive cartridge that provides 4MB RAM (the console has only 64KB native).
