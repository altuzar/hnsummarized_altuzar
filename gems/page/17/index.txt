36:T8f1,Splat4d is a streamable container for dynamic 3D gaussian splat sequences. It splits data into static background splats (stored once) and dynamic foreground splats using "deadband hold" tracks that only encode changes when they'd violate quantization error bounds. The format uses H.265-style closed GOPs with keyframes every N frames followed by delta-only P-frames, enabling independent chunk decoding and fast seeking without touching other chunks. Layout prioritizes key streams before delta streams within each GOP, allowing ~10% of a chunk to fetch during scrubs.

Compression comes from Morton-ordered splats, zigzag-coded deltas, byte-plane shuffling (Blosc-style), and per-stream zstd. Error bounds are pointwise and deterministic: position ±2mm, color ±4/255 per channel, opacity ±4/255, rotation exact, scale ±2% relative. Uses SZ/ZFP-style error-bounded quantization where step = 2×bound guarantees error ≤ bound by construction. All downstream math is integer, preventing temporal drift. Decoders (Rust and JavaScript) reconstruct bit-identical values.
