19:Td35,Mindwalk is a visualization tool that transforms opaque coding-agent session logs into navigable 3D maps. The core problem: reading raw JSONL doesn't reveal how an agent understood a task, which parts of the repo it deemed relevant, or whether its footprint matched the intended scope. The solution renders a repository as a "night map" and replays the session as light moving through it—where the agent searched, read, and edited, the map glows; everything else stays dark. This makes the agent's reasoning visible.

The tool is a single Go binary supporting Claude Code, Codex, and pi session logs. It keeps everything local by default; only optional session evaluation sends summaries (task wording, file paths, event digests) to your own local Claude or Codex CLI for judgement. The UI offers multiple views: tree/terrain layouts with glow proportional to file touch depth, touch states (seen in green, read in blue, edited in amber, unvisited in dark), and a playback deck with a cool/warm spectrum histogram (observation cool, mutation warm) to highlight editing phases. Click-to-jump timeline marks include context compactions, subagent launches, and user turns. An inspector pins file visit history, and an evaluate panel asks a local LLM to judge the session across four fixed process dimensions (exploration, scope, wandering, verification) plus task-specific criteria drafted from your request wording.

Installation is straightforward: curl the install script or build from source. Usage: mindwalk serve scans default agent directories and opens the UI in a browser; mindwalk analyze evaluates sessions; mindwalk map renders any repo's citymap with no session needed. The architecture deliberately separates trace (normalized file-touch events with subagent correlation), citymap (deterministic repo layout for comparable replays), and report (LLM-judged findings anchored to timeline events). The frontend is React/Three.js.
