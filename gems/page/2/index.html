    A tiny world model running games on a Raspberry Pi Pico 2 W(github.com)

    ★ A playable interactive demo of multiple games generated and played by tiny neural…

    A single looped transformer block (26k–131k int8 parameters) runs as a world model on a Raspberry Pi Pico 2 W, generating game frames from actions. A separate tiny actor network plays the generated games. Five games (Breakout, Pong, Flappy Bird, Doom-lite, Pac-Man lite) each fit in 361–600 KB flash and 227–460 KB RAM. The model predicts next frames at 83–100% accuracy across held-out test transitions, runs via WebAssembly, and supports on-device learning via Stream-X RL.
