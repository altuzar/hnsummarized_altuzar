37:T9ff,Ken Shirriff examines a core memory module from Spacelab's Mitra 125 MS minicomputer, which managed the experiments module aboard the Space Shuttle. Spacelab was a pressurized European laboratory carried in the Shuttle's cargo bay; three identical French computers ran it, with one managing the lab, one managing experiments, and one providing backup. The computer used magnetic core memory—128 KB total—storing bits in tiny ferrite rings that could be magnetized clockwise or counterclockwise.

Shirriff explains core memory's fundamentals: coincident current addressing used X and Y wires to select individual cores; hysteresis properties of special magnetic materials allowed precise current selection (half-current on each wire = full magnetization at intersection only). Reading a core destructively flipped it to zero; sensing the bit required a sense wire threaded through all cores. To stack multiple bits per word, cores were arranged in planes with shared X/Y signals but separate sense lines; an 18-bit Spacelab word required 18 planes.

The Spacelab memory was manufactured in 1980—late for core—and used advanced techniques. Its 2½D architecture eliminated inhibit lines by using separate X driver circuits for each bit, driving only the lines for bits that should be 1. Phase reversal further optimized wiring: pairing vertical wires with U-connections allowed one driver to select either wire by reversing current direction, halving the number of vertical drivers. Each core plane held 294,912 cores on a 1024×288 grid of ~0.8 mm diameter cores, with sense lines arranged to cancel noise pickup from nearby X lines through "bow tie" crossing patterns.
