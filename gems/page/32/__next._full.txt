2b:Tb57,The article provides an in-depth visual explanation of model quantization, starting with fundamentals: LLM parameters (weights) are the bulk of model size, with billions densely interconnected. Float32 gives 7 significant figures across ±3.4×10³⁸; float16 halves memory but drops to 3 sig figs; bfloat16 trades precision for range (2 sig figs but same range as float32). The article shows via interactive sliders how smaller floats approximate values with stepped precision—float4 can represent only ~16 distinct values.

Quantization maps large-range floats to small integers: simple rounding (float16→float4) fails catastrophically for LLMs because outliers dominate. Instead, **symmetric quantization** scales data by dividing by the absolute max, squishing values around zero (e.g., 0.89/7 ≈ 0.127 scale factor). This gives ~18% average error on example parameters. **Asymmetric quantization** handles uneven distributions better by finding a "zero point" offset, reducing error to ~8.5% in the same example.

Critically, quantization is applied **block-wise** (32-256 params per block) to limit outlier damage. Each block stores scale (symmetric) or scale+zero (asymmetric) as overhead. The article explains why outliers exist (largely unknown, but some are crucial "super weights"), and notes that production systems often preserve them unquantized or in separate tables.

Quality loss is measured via perplexity (next-token prediction entropy), KL divergence, and downstream task benchmarks. Tests on Qwen3.5 9B show Q4_K_M quantization (4-bit with extra storage optimizations) maintains strong performance; 27B models drop from 54GB (fp16) to 16GB, enabling consumer hardware (used RTX 3090 at $900).

The core challenge was register semantics. The Voodoo is deeply pipelined with multiple pixels in flight, so register writes cannot all behave identically. The author categorized all 430 register fields into four types: FIFO (enqueued, applied in order), FIFO+Stall (enqueued but waits for pipeline drain), Direct (immediate), and Float (float-to-fixed conversion).
