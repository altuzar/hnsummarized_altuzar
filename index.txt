The core challenge: SIMD varies wildly across platforms—some have fixed 128/256/512-bit vectors (x86, wasm), others variable sizes (ARM SVE: 128-2048 bits, RISC-V: 128-65536 bits). Vector masking differs too: some use bitmasks (AVX, NEON), others dedicated mask registers (AVX512, RVV), others per-byte masks (SVE). Rather than try to expose all hardware quirks, the simd package operates at the intersection of common operations—basic arithmetic, loads/stores, masking, comparisons, shifts—and fills gaps with efficient emulations using other SIMD instructions. Vector types are polymorphic (simd.Float32s, simd.Uint8s, etc.) with a runtime-determined length.
